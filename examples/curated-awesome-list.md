# ⭐ Curated Awesome List Archetype (`curated-awesome-list`)

## Target Audience
- **Community Developers** looking for structured, categorized resources on a specific tech domain.

## Recommended Structure
```
awesome-topic/
├── README.md                  # Categorized TOC, Shields badges, Markdown index
├── LICENSE
├── CONTRIBUTING.md            # Guidelines for submitting new links
└── .github/                   # PR issue & pull request templates
```
