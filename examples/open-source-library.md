# 📦 Open-Source Library & Python SDK Archetype (`open-source-library`)

## Target Audience
- **External Software Developers & Package Maintainers**.

## Recommended Structure
```
my-python-lib/
├── README.md                  # PyPI badges, 3-sec hook, 1-line pip install, quickstart
├── LICENSE
├── pyproject.toml / setup.py
├── src/pkg_name/              # Core modular python package
├── tests/                     # Pytest suite
├── docs/                      # Sphinx / MkDocs documentation
└── examples/                  # Standalone usage scripts
```
